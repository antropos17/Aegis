Use [Current development context](../docs/development/current-context.md) to
start work. Historical records retain their original dates, task language and
evidence limits; an old "next step" is not a new instruction.

Preserve historical receipts and append-only progress. Keep a task handoff short:
scope, source revision, changed files, checks actually run, unresolved evidence
and the next authorized action. Record local machine paths in private task
artifacts rather than copying them into this index or shared instructions.
