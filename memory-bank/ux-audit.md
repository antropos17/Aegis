# AEGIS UX Audit (read-only)

**Date:** 2026-06-03 · **Branch:** master (40a3257) · **Method:** ui-designer subagent (sonnet) UX pass + manual cross-check against real data-flow. Trust-code-over-docs; every finding below was re-verified from source (the subagent's severities and several claims were recalibrated — see "Corrections").

## Verdict

App-wide keyboard/focus hygiene is **mostly healthy** — `:focus-visible` ring is global (`global.css:174`), Esc handlers exist on every modal/palette, and tab-switching is instant (all 5 tabs stay mounted; inactive tabs gate their store-copies via `active`, so a switch is a pure CSS transition, not a remount). Severity is **color-encoded per row** (bars, glowing dots, badges) — readable at a glance, contrary to the subagent's "all rows equal."

The real UX surface is three things: **(1)** the primary intervention — Kill/Suspend an agent — is keyboard-inaccessible and mouse-buried with no affordance; **(2)** the Command Palette ships 9 dead "Coming soon" stubs out of 22 commands; **(3)** a quiet machine (no AI agent running) shows skeleton loaders forever instead of an empty state. Plus two narrow keyboard regressions (5 inputs opt out of the focus ring; AgentFormModal's Esc is swallowed by a `stopPropagation`).

Subagent was broadly **accurate on file:line locations**; its weakness was **severity calibration** (several P0s are P1/P2) and it **missed** the palette stubs (U4), skeleton-forever (U5), the Esc-`stopPropagation` bug (U6), and the fact that severity *is* already color-encoded.

## Healthy — no action

- **Tab-switch speed is good.** All 5 tabs mounted (`App.svelte:230`), inactive tabs gate their store-copies with `if(!active)return` and re-sync the instant `active` flips → switching is a pure 220ms CSS opacity/transform transition, no remount, no stale data. (Same model the perf-audit confirmed by-design; do not "fix" it.)
- **Esc-to-close exists on every modal/palette:** CommandPalette (`:74`), OptionsPanel (`:104`), App settings (`App.svelte:96-98`), AgentFormModal overlay (`:17`) — only AgentFormModal's is defeated (no autofocus + inner `stopPropagation`, U6); the rest work.
- **Global focus ring is present** (`global.css:174` `:focus-visible`), inherited by all buttons/pills/tabs/native selects (`FeedFilters.svelte:124-127`). Only the 5 opt-out inputs (U7/U11) and the non-focusable card (U1) miss it.
- **Hotkeys are guarded against input collisions:** bare `1-5/s/t/`/`` ignore events when focus is in an INPUT/TEXTAREA/contenteditable (`App.svelte:74-78`); Ctrl+1-5 + Ctrl/Cmd+K work from anywhere; palette swallows keys while open (`App.svelte:62`). No collision found.
- **Severity is color-encoded** at row level (ActivityFeed), group level (GroupedFeed badge `:161-172`), and filter level (FeedFilters pills) — legible at a glance.

## Suggested order (if acted on later)

1. **U1** — make AgentCard keyboard-operable (role/tabindex/onkeydown). Unblocks the core action for keyboard users. Highest priority for an "oversight" tool.
2. **U3 / U6 / U7** — feedback on kill/suspend; fix modal Esc; restore the 5 input focus rings. Low-effort, high-trust.
3. **U4** — wire or hide the 9 palette stubs (honesty + power-user value).
4. **U5 / U2** — real empty state for quiet machines; surface actions on the collapsed card.
5. **U8** — severity sort / critical-retention so criticals can't fall off the 200-cap.
6. **U9-U17** — polish; bundle opportunistically. **Do not** flatten the tab-mount model.
