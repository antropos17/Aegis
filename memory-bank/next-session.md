## Следующая конкретная задача — B2, проект подключения ETW

Создай ветку `codex/etw-sensor-design` от актуального `origin/master`. Подготовь
`docs/roadmap/etw-sensor-design.md`, обнови статус в ROADMAP и progress. Это первый
проект решения; производственное подключение пока не реализовано и не утверждено
самими замерами. Если такой документ уже появился, продолжи существующую работу.

1. Прочитай recon, результаты измерений и текущие контракты procsnap, identity,
   file events и Sensor Health. Применяй навыки проекта при чтении/правке исходников.
2. Опиши границу C# sidecar / Electron, способ запуска и остановки с нужными правами,
   передачу событий, идентичность процесса, пределы очередей, потери и восстановление.
3. Отдельно определи неизвестный путь/агент, preopened/mmap, отказ PID-фильтра,
   потерю naming-событий, переиспользование указателей и связь с health. Не выдавай
   кандидатов корреляции за подтверждённое чтение конкретным агентом.
4. Предложи небольшой первый backend-блок B3 с проверяемыми критериями. Для каждого
   ещё не доказанного решения укажи необходимый точечный эксперимент или ограничение
   поддержки. Не закрывай все B1-вопросы и не объявляй production готовым.

На этом шаге не подключай датчик, не меняй UI, зависимости, workflows, установку
или бюджет по умолчанию. Проверяй фактические контракты; для docs выполни применимые
проверки и обычный разрешённый git-цикл через PR, пять CI-контекстов и merge.
