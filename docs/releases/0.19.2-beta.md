# AEGIS 0.19.2-beta

This Windows beta improves recovery after file-watch failures, keeps packaged
renderer loading local and fixes Linux process controls for stale observations.

## Changes

- A completely lost file-watch plan receives three fast retries, then recovery
  probes after a five-minute cooldown. A healthy plan resets the retry budget.
- Packaged Electron always loads its local production renderer. Development URL
  variables cannot redirect a packaged application.
- POSIX process parsers reject malformed PID values. Linux pause, resume and
  terminate compare the observed boot identity and process start ticks against
  a pinned process descriptor before signalling that descriptor.
- IPv4 link-local addresses are excluded from public endpoint lookup.
- Operational-log boundaries and audit-index invariants have additional regression
  checks. TypeScript advances to 6.0.3; dependency updates defer unsupported
  TypeScript and Vite majors. The source-map parser advances to 1.2.2.

## Download and verify

Download the Windows x64 installer, `manifest.json` and `manifest.json.sig` from
the [release assets](https://github.com/antropos17/Aegis/releases/tag/aegis-v0.19.2-beta).
From a checkout of `aegis-v0.19.2-beta`, verify the files with the
[offline verifier](https://github.com/antropos17/Aegis/blob/aegis-v0.19.2-beta/scripts/release-verify.js)
and its committed public key:

```powershell
node scripts/release-verify.js --dir <download-directory>
```

The Ed25519 manifest authenticates the asset bytes. The installer and application
do not have Windows Authenticode signatures. The 0.17.0-alpha updater does not
discover beta releases; verify and install the first beta manually when upgrading
from that version.

## Verification and beta limits

The release PR and merged master passed all five required CI contexts. The release
workflow built, signed and verified all three assets. Downloaded assets passed
offline signature, hash and size verification. The extracted application passed
11 workspaces, six exports, configuration import, settings across restart and
Electron hardening without renderer errors. It uses Electron 44.5.1, Node
24.21.0, Chromium 152.0.7977.130 and Undici 7.29.1.

Windows is the primary platform. The Linux process-control kernel path passed an
owned-child probe under Ubuntu in WSL2; a standalone Linux desktop and macOS remain
experimental. Linux controls require `/usr/bin/python3` 3.9+ and kernel pidfd
support; unavailable support produces an explicit error.

Installer installation, upgrade and uninstall in a disposable Windows environment,
long-duration production token accounting, broader enforcement and screen-reader
speech remain unqualified. Monitoring observes activity; process and execution
actions remain explicit. Sensor health does not establish complete capture.
The [beta readiness record](https://github.com/antropos17/Aegis/blob/master/docs/BETA-READINESS.md)
contains the dated checks and remaining limits.
