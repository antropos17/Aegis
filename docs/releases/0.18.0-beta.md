# 0.18.0-beta — draft release notes

This is a preparation draft. No beta installer is published by this document.

## Install and upgrade

Download the Windows installer, `manifest.json` and `manifest.json.sig` from the
same [release](https://github.com/antropos17/Aegis/releases), then follow
[offline verification](../RELEASE-VERIFICATION.md) before installing. Release
assets must all be present; an upload still in progress is not ready to install.

**From 0.17.0-alpha, install this first beta manually.** Its updater cannot discover
beta tags. Subsequent beta installations accept newer signed beta or stable
releases. Keep the existing user-data directory; reinstalling does not require
deleting your settings, audit history or saved alert reviews.

## Changes for users

- Observatory groups monitoring, investigation, local review and selected-action
  tools into task-oriented workspaces. Sensitive activity can be reviewed in Alerts
  with saved review state and guarded links to current process controls.
- Observation outages, partial identity, skipped scans and sensor failures now
  retain explicit uncertainty. Audit delivery reports pending writes and session
  loss separately from readable retained history. History counters load in bounded
  steps, and sensor labels update with the selected interface language.
- Network, file attribution, operational logs, path rules, report retention and
  IPC batching received focused correctness and bounded-work fixes. Claude
  transcripts are processed in bounded batches and resume on later scans.
- Windows supports explicitly reviewed selected Job/AppContainer actions. Local
  security and action checks expose their captured result and unsupported scope.
  Signed updates understand the beta channel, and packaging builds the current
  production interface before creating an application artifact.

## Supported scope and known limits

Windows monitoring is the primary scope; macOS/Linux remain experimental.
Monitoring does not automatically intercept every command or contain an agent.
Selected-action routes require explicit configuration. VM/provider qualification
fixtures are development evidence; broader enforcement admission remains disabled.

Token totals are observed subtotals while a backlog drains; unsupported or oversized
records reduce coverage. Cache reads and five-minute/one-hour writes use separate
local prices for supported Claude models; an unknown write duration marks the
price as approximate. Dollar amounts remain local estimates rather than provider
bills. Historical token records and transcript deduplication state are retained
for the application lifetime; long-running churn can grow memory and IPC payloads.
See [beta readiness](../BETA-READINESS.md) for the current gates and unresolved items.
