# Backend and frontend audit — 2026-09-09

This is the current audit record. Earlier integration reports retain their historical results; they are not evidence for this patch.

## Scope and confirmed changes

Three parallel audits covered resource/token collection, frontend mutation workflows, and IPC/settings/export security. A separate implementation pass checked host freshness and custom catalog recognition. Network monitoring received a bounded read-only review without a newly reproduced defect.

- Missing or malformed CPU/RAM values remain unavailable through normalization and cache reads.
- Inherited JavaScript model names use fallback pricing; invalid token rows and thrown non-Error values cannot stop remaining adapters or poison costs.
- Settings saves preserve newer drafts; provider requests cannot clear a reopened editor; catalog deletions and permission reset/save actions cannot overlap.
- Successful scan-interval changes update the renderer freshness deadline; superseded startup responses and errors cannot overwrite live data.
- Settings validate every persisted field, nested permissions, custom signatures, exceptions and watchlist before mutation. Invalid disk fields recover to defaults while valid preferences survive.
- API keys are encrypted before persistence. Unavailable or Linux basic_text storage cannot write plaintext. Locked encrypted keys survive unrelated saves and failed replacements; explicit removal has a separate save option.
- Synchronous custom regex matching accepts a conservative subset: no repeated groups, backreferences, lookarounds or multiple variable repetitions. Previously stored unsupported patterns are skipped.
- CSV exports prefix formula-like text cells and escape carriage returns.
- Validated custom catalog signatures participate in each process scan. Built-in identity/process-name ownership takes priority; catalog edits do not modify the bundled database or identity stamping.

## Remaining limits

Source delivery time is not an OS sample timestamp; resource values can come from the five-second collector cache. Token telemetry currently has a Claude Code adapter; unsupported providers remain unavailable/partial. Full settings snapshots can still conflict across independent windows; this pass prevents the reproduced local workflow races. Native macOS/Linux execution, paid provider calls, and actions against user processes were not exercised.

The broader security review also noted sender/navigation/process-control hardening opportunities without a confirmed end-to-end exploit. No claim of exhaustive security coverage or user visual approval is made.
