# Observation completeness — 10 September 2026

This pass fixes two source-backed data-loss cases. Network identity previously checked only the first PTR name and cached unsuccessful lookups for five minutes. It now tries distinct candidates until one forward-confirms, retries negative results after 30 seconds, and rejects expired or clock-invalid cache entries. Concurrent lookups share work for equivalent IP addresses and for the same forward hostname. The shared cache is bounded to 500 entries; each scan retains its own results so cache eviction cannot erase an already resolved endpoint.

File-watch debouncing previously suppressed every further action on a path for two seconds. It now suppresses only consecutive notifications with the same action, stamped identity, agent, attribution and sensitivity evidence. Rapid create/modify/delete/recreate sequences, newly available ownership evidence and notifications after a backwards clock jump reach the existing activity/audit/sequence delivery path. This does not strengthen inferred ownership into confirmed ownership, read file contents, or assign an unowned event to a selected agent.

A deterministic comparison against the previous source used 50 distinct endpoints, one common PTR hostname and 50 stamped owners. Before: 50 reverse plus 50 forward resolver calls. After: 50 reverse plus one forward resolver call. Both retained all 50 connections and owners. These are injected resolver-operation counts, not measurements of real DNS latency, total application CPU, or long-session memory. An additional regression covers 550 endpoints without losing same-scan DNS evidence.

Focused tests cover multiple PTR candidates, unconfirmed names, concurrent calls, IPv6 aliases, negative and positive expiry, backwards clocks, reset generations, large scans and file-event transitions. Existing network health and attribution tests remain applicable. Domains without verifiable DNS remain unverified; missing process birth times and unsupported sensor attribution are not repaired by these changes.
